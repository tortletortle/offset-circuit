# 错位电路 V0.8 — 联合调试

在 V0.7 基础上新增空间站运行控制台；保留六关、随机生成、故障诊断与竞争冒险实验。

## 运行
解压后双击 index.html，或 Windows 下双击“启动游戏.bat”。不需要网络和 API。游戏页内点击“进入联合调试”。

## 新机制
- 六个已验收控制器参与运行；工作台重新练习不会覆盖已验收控制器。
- 双路输入通过主供电控制器的实际 AND/OR 输出决定主母线与备用照明。
- 气闸依赖电源、警报、通风；通信依赖电源、通风；主控依赖其余系统。
- 超过任务的抽象负载额度时断路器锁存跳闸；切除负载后手动复位。
- 四个运行任务依次解锁，成功记录保存到 localStorage（若浏览器允许）。每次重新加载、切换任务会重置部署，不会自动接通负载。
- 其余控制器采用已验收逻辑布局的固定测试工况作为允许运行信号；这是离散游戏模型，不是电力系统或真实气闸动态仿真。

## 测试
`python build.py` 从 base_v07.html 生成 index.html。`python test.py` 需要 Python Playwright 和 Chromium（脚本指定 /usr/bin/chromium）。85 项浏览器检查通过；独立枚举 32768 个状态通过。测试使用 set_content 加载及模拟 Web Storage，因为环境禁止 HTTP/file 导航。测试截图 preview.png 和 mobile.png 为自动化浏览器截图；未做真机、人类留存或真实浏览器存档长期测试。

## 本仓库基线
`index.html` 与 V0.8 原始运行文件完全一致。原发行包的构建脚本、测试脚本和截图暂未同步至本仓库；上方测试结果是原版本记录，不代表远程 CI 已运行。
